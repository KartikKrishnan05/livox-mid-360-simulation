# AgileX Scout Mini

Model files copied unchanged from ignc-kit's `gazebo_sim` package
(`ignc_ws/src/gazebo/gazebo_sim/models/scout_mini`, Apache-2.0, see `LICENSE`):

* `meshes/scout_mini_base_link.dae`, `meshes/wheel.dae`

The robot description is `urdf/scout_mini.urdf.xacro` in this package, adapted from that
package's `scout_mini.xacro` (same links, joints, masses, wheel geometry and gz plugins)
with a Livox Mid-360 on a mounting plate on the top deck.
